# Bank Account Management System

A console-based Java application for managing bank accounts, customers, and
transactions. It demonstrates core object-oriented programming principles,
encapsulation, inheritance, polymorphism, abstraction, and composition, and,
from Phase III onward, the Collections Framework, functional programming with
Streams and lambdas, File I/O with NIO, regular expressions, and concurrency.

Built across three lab phases, each building on the last:

- **Phase I: Java Basics and OOP** (implemented, merged into `main`)
- **Phase II: Clean Code, Git, and Testing** (implemented, merged into `main`)
- **Phase III: Advanced Java** (Collections, Functional Programming, File I/O, Regex,
  Concurrency) (implemented, merged into `main`)

The project lives in [`bank-account-management-system/`](bank-account-management-system/). See
its [README](bank-account-management-system/README.md) for features, setup, and how to run,
[`docs/git-workflow.md`](bank-account-management-system/docs/git-workflow.md) for the branch and
cherry-pick history behind Phase Two, and
[`docs/collections-architecture.md`](bank-account-management-system/docs/collections-architecture.md)
for the Collections Framework design decisions behind Phase Three.
